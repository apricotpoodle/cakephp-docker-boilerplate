# Décisions d’architecture du dépôt racine

Ce registre documente les décisions relatives à l’infrastructure Docker, au
`Makefile` et à l’organisation de ce dépôt. Les décisions métier et
applicatives sont conservées dans le dépôt `app/`, selon son ADR 0021
(`app/docs/adr/0021-arborescence-documentation-applicative.md`).

Chaque ADR racine possède son propre numéro séquentiel. Une nouvelle décision
est créée au statut **Proposé**, ajoutée à cet index puis soumise à revue.
Les ADR **Acceptés** décrivent les conventions en vigueur ; une évolution
importante fait l’objet d’un nouvel ADR plutôt que d’une modification
rétroactive de la décision acceptée.
